# Haley Morgan — Research, Data & Operations Portfolio

Personal GitHub Pages portfolio for applied statistics, research, data quality, workflow design, and operational improvement.

## Website

Once GitHub Pages is enabled under **Settings → Pages**, this site can be published at https://haleyemorgan.github.io/.

- Source: Deploy from a branch
- Branch: main
- Folder: /(root)

## Content and privacy

The featured projects are high-level descriptions, not shared agency materials. Planned demos should be developed **independently** with fully synthetic data. Do not commit agency files, internal screenshots, actual operational code, records, identifiers, confidential procedures, credentials, or restricted datasets without explicit authorization.

## Roadmap

2. Build an independent fictional information-lookup demo.

4. Build a generic task-tracking prototype.

## Editing

Edit `index.html` for text and links; edit `styles.css` for styling. GitHub Pages serves the site as static HTML/CSS without a build system.
